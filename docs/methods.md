# evoSim v0.1.6 — 当前材料与方法

更新：2026-10-28。对应 shared-chemical-1 / slim-qtl-2，SLiM 5.2。公式以 [model.md](model.md) 为准；本版只做小规模实现核查，检查状态见 [实施记录](plan/v0.1.6_implementation.md)。

## 1. 实体、输入与初始化

YAML 指定流程与通用参数，CSV 指定物种、竞争、位点、等位、创始频率和参考面板。植物具双性功能且严格异交，昆虫雌雄异体，物种 ID 固定。创始同源拷贝按物种/位点频率独立抽样；位置按配置或周期格均匀生成，昆虫性别按创始雌性概率抽样。创始个体是外给成虫，出生寄主 unknown，不能以位置或首次选择倒填。

植物有6个、昆虫8个抽象 QTL，每原发轴2位点；数量和独立连锁群是理论输入。植物效应3维、昆虫4维，加性拷贝效应乘 effect_scale 后加背景并截断，默认系数1/2、背景0、范围[0,1]。植物原发 x=(x_N,x_S,x_V)，昆虫为(I_N,I_S,A_S,A_V)。

## 2. 每轮成年状态与产卵

reproduction_round=t 开始于 P_t 与 Adult(t)。Adult(t) 已通过前轮幼虫存活、完成扩散，不再抽幼虫存活，不需要本轮寄主。以当前成年坐标按同种、雌雄和 insect_mate_radius 形成候选父本池。母体 Fm=max(0,1−cIΣI_m)，有父本的雌成虫抽 Poisson(lambda_egg*Fm) 潜在卵，上一轮摄食收益不再乘入产量；无父本或 Fm=0 不生成卵。insect_offspring_lambda 保留键名但改为潜在卵率，旧数值只是示例。

植物从同一遗传状态输出 D=(x_N,x_S)、V=(eta*x_S,x_V)。eta 固定不演化；化学能力、线索与窗口都是归一化尺度，不等于浓度或挥发通量。不模拟诱导、储存/传播动力学。

每潜在卵从母体搜索半径内无放回抽至多 candidate_size 植物，按母亲 A 与 V 的加权平方距离、softmax 和外部拒绝选择；外部效用不乘 tau。每卵独立，可同母异寄主；不读取未出生子代 I。拒绝/无候选不生成子代、不扣资源；成功卵逐子代从母本父本池均匀有放回抽父本，再交给 SLiM。

## 3. 子代遗传与幼虫窗口

Python 给出出生数、真实双亲索引与亲本基因型，SLiM addCrossed 形成母父各一配子。独立连锁群自由组合，群内 Haldane r=(1−exp(−2d_Morgan))/2。CSV 指定逐拷贝 QTL 突变概率和正态增量；默认0.01与目标坐标SD0.02是理论示例，不是核苷酸率。日志记录亲本同源来源/标记切换，不记录完整交换次数，也不产生局部基因组树序列。

新生幼虫有固定出生植物 ID/物种，取食用它自己的 I：q=min(1,min_(D_j>0) I_j/D_j)，全零 D 时 q=1。d=dmax*q，同株总需求超过 R 时同时按同一比例缩减，得到 x、植物总损失 X、g=x/dmax、h=X/R，保证 Σx=ΣX、X≤R。幼虫不主动换寄主，无先到先得、额外毒死或重复成本存活惩罚。每幼虫仅抽一次 Bernoulli(g)。全部出生和死亡记录保留；幸存者从自己的出生寄主格扩散成 adult_cohort=t+1，ID 不变。

## 4. 植物受食后更新

植物在同批幼虫消费后抽 S_P=sP0+(1−sP0)(1−h) 的一次存活。母源成本 Fm=max(0,1−cD(x_N+x_S)−cV*x_V)，共享合成投入计一次，不按 V 均值收费，不声称闭合碳预算。局部密度 phi 按代初数量、包含自身计算。

植物母本/父本都需存活，同种非自身且在 pollen_radius 内；不以 Fm 筛父本。合格母本以 Poisson(lambda_P*Fm*phi) 生有效植物后代，逐后代均匀有放回选父，经 SLiM 后从母株格扩散。植物 lambda 仍为有效后代，不改为逐枚种子。P_(t+1) 和 Adult(t+1) 整体替换亲代，世代不重叠。

## 5. 身份、阶段贡献和原子提交

每成功卵保留 event_id、maternal_id、paternal_id、offspring_id、birth_host_id/species；reproduction_round=t 与 adult_cohort=t+1 分开，offspring.generation=t+1。主键须含 kind，因为两类群 ID 各自唯一。

对所有出生子代、幸存补充子代分别重算母/父计数及 w=(Bm+Bf)/2。出生账本总和等于出生数，补充账本等于下一代成年数；等位频率分解标 stage。按亲本出生背景→子代出生背景各1/2构建两阶段矩阵，含 unknown，并分别守恒。这是来源贡献计数，不是有效基因流率；双亲是否异背景单独标同/异/unknown。

遗传、资源、存活、扩散全部验证后才原子提交。失败更新不提交半轮实际贡献；计算上限停止而不截断人口。终点 t=T 不生成子代，只保留快照与参考观察，未执行贡献缺失；实际已执行但零后代的计数才为零，零分母比例未定义。

## 6. 观察、网络和核查

固定物种网络按真实幼虫消费和成功补充计边；亲本出生背景的实际滞后出生/补充贡献另表，不把当轮产卵位置当亲本幼虫经历。出生背景群每代归类、含 unknown，可消失再现；完整亲子 DAG 保留全部出生者，不生成候选独立谱系或新物种。

标准化 A/I 参考反应为成年基因型的反事实功能诊断，不表示成虫当轮真实取食。参考 p 排除拒绝、q 是无竞争上限；观察不消耗模拟随机流或反馈选择。历史跨时间/绘图入口是否支持新生活史以 [results.md](results.md) 为准，不能无条件复用旧贡献定义。

独立审计检查快照/等位重建、实际双亲、两阶段贡献、源→目的矩阵、资源和网络守恒及终点边界，不把实现正确当作生物验证。全部文献和支持层次见 [model.md§7–8](model.md) 与 [审定计划§9](plan/v0.1.6_plan.md)；Bruce/Hare 仅摘要核实，具体逐卵函数、有限资源与线性存活均含项目假设。
