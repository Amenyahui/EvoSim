# evoSim v0.1.5 — 当前材料与方法

更新：2026-10-28。方法对应 shared-chemical-1 / slim-qtl-2；软件目标版本保持0.1.5，SLiM执行器保持5.2。正式数学定义见 [model.md](model.md)，本轮只作实现正确性验证，不运行长期演化研究。

## 1. 实体、输入与初始化

植物和昆虫分别为具有ID、同种标签、位置和二倍体基因型的个体。植物有两种生殖功能且严格异交，昆虫雌雄异体。物种集合由CSV预先定义，当前无动态成种。

YAML指定流程及通用参数，CSV指定物种、竞争、位点、等位、创始频率和固定参考面板。创始同源拷贝按物种/位点频率独立抽样；初始位置按配置或周期网格上的均匀分布生成；昆虫性别按配置的雌性概率独立抽样。默认植物原发性状为三轴、6QTL，昆虫为四轴、8QTL，每轴2位点；数量为理论输入。

## 2. 遗传状态至功能输出

两类群各自的性状为背景加两份拷贝效应之和乘 effect_scale，再按 phenotype_map.bounds 截断；默认系数1/2、背景0、边界[0,1]。植物效应顺序为(x_N,x_S,x_V)，昆虫为(I_N,I_S,A_S,A_V)。等位向量真实长度分别为3和4。

\[
D=(x_N,x_S),\qquad V=(\eta x_S,x_V).
\]

eta_shared在[0,1]、固定不演化；默认1是统一归一化尺度的参考，不是实测挥发率。x为化学能力/投入性状，V为挥发线索强度，均不直接等于分子浓度。映射在同一个遗传状态上确定性计算，不额外随机生成D/V。观察窗口沿用一个繁殖前取食世代，假定释放不显著耗尽防御储量或由合成补足，无诱导和传播动力学。[C1,C2]

## 3. 寄主选择与资源结算

每只昆虫从搜索半径内的植物个体中无放回均匀抽取至多candidate_size株；按既有加权V/A平方距离生成气味效用，softmax与外部拒绝选项归一化。外部效用不乘τ，强制选择模式省去拒绝选项。该过程仅改变局部候选中的选择，不模拟气味介导的远距离发现。[C3]

选择给定后，最限制性I/D比值决定q，上限1；零防御通道不限制，全部防御零时q=1。需求d=dmax*q；同株总需求超过R时按相同比例缩减。实际摄入x、植物损失X、昆虫收益g=x/dmax和植物损伤h=X/R来自同一资源账本。资源与需求有共同单位和窗口，保证Σx=ΣX、X≤R；无先到先得或新毒理机制。[C5]

## 4. 成本、存活及繁殖

\[
F_m^P=\max(0,1-c_D(x_N+x_S)-c_Vx_V),\qquad
F_m^H=\max(0,1-c_I\sum I).
\]

共享模块的基本合成投入只计一次，独立挥发模块直接按x_V收费，不再按mean(V)计费；额外共享释放成本未模拟。成本线性、cD对两模块等权及母源限定为理论简化，系数未实测校准。[C4,C5]

植物存活概率S_P=sP0+(1−sP0)(1−h)，昆虫S_H=g，各自一次伯努利抽样。母株邻域竞争乘子φ折减母源条件均值；昆虫φ=1。父本资格只依赖存活、角色、同种、距离、异交及现有寄主条件，不以Fm筛选。

对母源角色，潜在父本池C_i^0先按角色/空间建立，实际池C_i保留幸存者。母本存活且池非空时B_i^m~Poisson(ν_i)，ν_i=λ_s F_{m,i}φ_i，否则零。Fm=0使母源产量必为零，但可父源供源。空乘积为1，配偶概率π_i=1−∏_{j∈C_i^0}(1−S_j)，母源无条件均值S_iπ_iν_i，方差为S_iπ_iν_i+S_iπ_i(1−S_iπ_i)ν_i²。雄虫实际母源计数为零、母源矩为NA；其conditional_mu仅为共有函数的代数诊断。

每个有效后代从母本实际池均匀、有放回地抽父本。无花粉/精子容量、性选择、储精或交配次数模型；允许同母子代异父。定义B_i^f为父源子代计数、w_i^G=(B_i^m+B_i^f)/2；每个已提交物种更新有ΣB^m=ΣB^f=Σw^G=N_next。不将SFm再乘到贡献上。

## 5. SLiM遗传、后代扩散及原子提交

Python给出出生数、双亲索引与基因型，SLiM addCrossed原生形成双亲配子。独立连锁群自由组合，群内按Haldane标记概率r=(1−exp(−2d_Morgan))/2配置。逐拷贝QTL突变在Eidos中使用CSV定义的概率和效应增量；默认均值0、目标坐标SD0.02，未改变其核。来源日志记录同源拷贝及标记切换，不记录完整交换次数。

每次调用按该类群使用3或4维效应；跨类群未使用的等位ID行仅作零占位，不构成额外植物性状。默认μ=0.01时植物至少一次新突变的概率为1−0.99^12，昆虫为1−0.99^16；不是核苷酸率。遗传实现参考Haller & Messer (2023), https://doi.org/10.1086/723601。

植物后代从母株、昆虫后代从母虫本代寄主格按原周期扩散规则移动。后代验证完成才整体替换亲代、提交双亲与等位贡献。安全停止不截断出生数、不提交半代；终点及失败更新的实际贡献为NA。无移民、种子库或成年跨代存续。

## 6. 观察、审计与证据边界

原发x及派生D/V、I/A、基因型和空间状态按ID保存。独立审计由原始等位效应重建3/4维性状，单独计算D/V及成本，不调用生产表型函数来“自证”。它同时核对资源、父本池、母源矩、双亲传递与贡献守恒。

保留固定参考、跨时间功能评估及网络分析入口，并适配三模块；本轮不执行其演化分析。历史记录按保存协议解读，不把旧Z当x，也不重写指纹。SFm不是完整适合度，边持续性不是永久稳定。

C1–C5文献、DOI及其支持边界见 [model.md §7](model.md)；前三类化学/嗅觉背景不验证当前线性映射或距离核。繁殖假设的原始证据和限制见 [繁殖审查](plan/v0.1.5_reproduction.md)。代码与公式一一对应不等于生物机制获实证证明。
