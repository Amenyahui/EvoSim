# evoSim v0.1.4 — 当前实现架构

更新：2026-10-27。遗传协议 `slim-qtl-1`。本文描述已实现的代码，不再将旧版建议接口列为完成项。

## 1. 科学职责与因果顺序

模型连接基因型、功能性状、个体互作及多物种网络。植物 D/Z 和昆虫 I/A 来自各自的二倍体 QTL；植物气味 V 来自 D/Z。局部遇见和气味选择决定取食对象，D/I 匹配及共享资源决定摄入与损伤，存活及有性繁殖决定双亲遗传贡献，SLiM 产生下一代基因型。

`P1/P2/H1` 是 CSV 定义的物种标签；Agent 是每株植物和每只昆虫。当前没有新物种生成。网络由个体事件聚合，不控制个体行为。

## 2. 实际文件及职责

以下路径相对于 `evo_sim/models/plant_insect/`。

| 文件或目录 | 实际职责 |
| --- | --- |
| `config.yaml`、`configs/*.yaml`、`inputs/*.csv` | 调度、通用参数、场景以及物种和遗传输入 |
| `helpers/config.py` | 展开参数的类型、范围、生活史与协议验证 |
| `helpers/agents.py` | 植物/昆虫的逐个体数组、状态与快照 |
| `helpers/traits.py`、`voc.py` | D/Z→V、气味效用、选择概率、D/I 利用及投入成本 |
| `helpers/ecology.py` | 候选寄主选择、比例资源分配和守恒账本 |
| `helpers/spatial.py`、`demography.py` | 空间邻域、交配候选、生存与繁殖计算 |
| `helpers/genetics.py`、`slim_backend.py`、`slim_reproduction.slim` | 遗传输入、SLiM 子进程桥接、原生配子与 QTL 突变、来源记录 |
| `helpers/observations.py` | 固定祖先植物面板上的个体条件选择与利用反应 |
| `substeps/` | 组织生态、生存繁殖及世代更新，提交完整账本 |
| `batch.py`、`audit.py` | 批次运行、原始数据和哈希保存、独立审计 |
| `analysis/summarize_coevolution.py` | v0.1.4 新增：跨时间功能评估、双亲贡献差异、寄主与网络边持续性 |

通用调度位于 `evo_sim/core/`。运行入口和模块组织不要求另造一个“共同演化引擎”。

## 3. 一代的执行

1. 根据 CSV 初始频率生成创始二倍体、性别和位置；此步仅在初始化发生。
2. 每代由个体 D/Z 生成 V，昆虫从局部候选中选择寄主或拒绝。
3. 所有选择确定后，按共享植物资源同时结算摄入 g 和损伤 h。
4. 按植物/昆虫的生存概率分别抽样；成本 F 影响条件母源产量，并通过 F>0 决定父源资格。
5. 幸存个体在同种、规定半径和角色条件内交配；父本均匀有放回抽样。植物禁止自交。
6. SLiM `addCrossed()` 执行双亲传递与标记重组；Eidos 定义的逐拷贝 QTL 突变产生新效应，Python 映射后代表型。
7. 后代从母源位置扩散，整体替换亲代；更新成功后才提交真实繁殖贡献。
8. 保存逐代状态与账本。终点状态观察互作，但不额外生成下一代。

植物密度因子在母株邻域计算，折减母源产子均值；不是后代落点的独立招募概率。配置中的 `offspring_recruitment` 为保留的历史阶段标签，含义见 [参数说明](parameters.md)。

## 4. SLiM 与 Python 的边界

SLiM 5.2 实际承担染色体遗传，而非仅作为理论参考。Python 确定生态事件、双亲及出生数；SLiM 不另施加一轮生态选择。独立连锁群使用独立染色体，多位点群按 Haldane 标记重组概率配置。来源标记识别纯合亲本的拷贝来源；不从来源切换反推完整交换次数。

这不是全基因组核苷酸或真实基因家族模型。原生重组与项目自定义 QTL 突变的区别见 [SLiM 接入说明](../README_v0.1.3.md)。

## 5. v0.1.4 观察与演化分离

新增汇总只读取已保存结果，不调用生态随机数、SLiM 或世代更新。两时期所有植物与昆虫个体按物种两两组成独立单寄主试验，计算四种时间组合。每个试验只有一株植物、一只昆虫及拒绝选项；无竞争、无配偶和密度效应。全体个体组合精确平均，不用物种平均表型替代非线性反应。

实际轨迹分析另外连接机会、接受、参考选择/利用、摄入和繁殖网络；逐个体双亲贡献与性状按 ID 对齐，计算贡献加权亲代均值及后代差额。固定面板与时间交叉评估互补，不能互换。

设计读取 `analysis/v014_analysis.yaml`；可由批次根目录完整的 `analysis.yaml` 替代。持续窗口和边权阈值仅用于观察，不能反馈到模型。所有新 CSV 写入批次 `data/summary/`，不修改原始结果。

## 6. 审计、停止与边界

每份实际读取的原始输入都与该运行 `metadata.json` 的 `output_sha256` 对照；新增元数据记录输入哈希、分析源码、设计、状态表和原审计报告的哈希。历史模拟源码与当前分析源码分别记录，不改写旧源码哈希。哈希支持意外改动检测，不是恶意篡改下的签名保证。

计算安全停止不等于灭绝；分析保留运行状态、实际终点及可用窗口。终代或未提交更新的繁殖贡献是缺失，不是零。灭绝物种的交叉试验显示样本数零及指标缺失，不回退到最后存活代。

当前没有固定功能分布的 2×2 演化开关、自动适应判决、成种、真实 OR/P450 功能映射或扰动恢复实验。它们的理论需求见 [版本计划](plan/v0.1.4_plan.md)。

- Haller & Messer (2023), [10.1086/723601](https://doi.org/10.1086/723601)：支持多物种显式遗传模拟的方法，不验证本项目的生态函数。
- Grimm et al. (2020), [10.18564/jasss.4259](https://doi.org/10.18564/jasss.4259)：支持明确模型目的、实体、尺度与过程的 ODD 描述。
- Price (1970), [10.1038/227520a0](https://doi.org/10.1038/227520a0)：贡献差异与传递残差的理论基础；实现定义和推导见 [模型](model.md)。
