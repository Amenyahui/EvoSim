# v0.1.7 功能机制核定报告

日期：2026-10-29。按功能核定计划由两名Sol medium子代理执行A–E及F；主任务复核数据并完成汇总。两名代理在结果落盘后分别遇到额度和网络限制，没有完成各自原定独立报告；本报告直接依据已保存的脚本、表格、日志和输入指纹，不冒称已完成额外同行评审。

## 1. 核定结论

功能映射和固定性对照的实现检查通过，但本轮**没有建立双向适应的证据**。固定祖先寄主面板上的利用表现全部饱和，12个小规模对照全部在第4或5代灭绝，无法据此判断长期共同适应。已有4次植物灭绝的末轮直接瓶颈均是存活后缺少局部兼容异交配偶；这不等于整个衰退过程只由配偶限制引起。

没有修改核心生物规则、没有新增定居/花期/成种机制，也没有通过挑选种子或调整参数维持种群。正式200代批次原数据不变。全部新检查产物在 `codex/validation/v017_functional_verification_20261029/`。

## 2. 功能能力与限制

| 层次 | 已实现 | 本轮不能宣称 |
| --- | --- | --- |
| 植物化学 | 三个可遗传投入轴生成防御与挥发线索，成本及食害反馈影响后代贡献 | 真实合成网络、植物新隔离机制 |
| 感知 | 两模块表达与调谐中心生成响应，经固定价性和拒绝选项决定选择 | 单模块谱宽进化、受体家族扩张、真实OR/OBP回路 |
| 处理 | 两模块表达与调谐中心决定底物处理容量，再经瓶颈与资源分配影响幼虫表现 | 体外酶动力学、真实P450/GST/UGT家族；容量变化必然导致表现变化 |
| 成本 | 感知和处理表达线性折减母体潜在卵 | 跨性别、全生活史能量预算或经验校准成本 |
| 分化观察 | 基因型及亲子贡献记录操作性分化 | 聚类分裂等同成种 |

固定模块数、高斯核、一维化学特征、固定宽度、容量预算及线性成本仍是模型假说。本次未新增文献检索；证据边界沿用已有功能文献报告，不把原始研究对机制存在的支持等同于对这些公式的验证。

## 3. 固定寄主条件的B–D检查

具体面板取正式批次 `qtl_mutating/rep01` 第0代每种植物按存储顺序的前4株，共8株，匹配现有候选数；将它们设为每只昆虫都可达的同一候选集合，固定D、VOC和资源。植物ID、值及源哈希见 `fixed_panel.json`。这是有限祖先面板，不是跨所有寄主或化学梯度的完整谱。

对6个重复的第0、50、100、150、200代个体调用真实选择函数，包含拒绝；逐只幼虫、逐株植物独立计算摄食，无测试个体间竞争。所有30个昆虫端点存在。保留个体结果与分位数，但科学重复仍是6条独立轨迹，不能用个体数扩大重复数。

- 按“重复×代次×寄主种”的群体均值，接受后的条件寄主份额范围为0.498730–0.501270，接近均分；拒绝率均值范围0.040442–0.044174。这里只检出了有限面板上的微小响应差异，不能据此断言已有专化。
- 所有被检个体对8株寄主的利用系数q和独立幼虫存活期望均为1。该面板处于利用饱和区；即使处理容量改变，也没有产生可检测的表现提高。此结果不代表实际200代内所有寄主与竞争条件都处于饱和。
- 原成本下母体繁殖倍率的群体均值为0.714580–0.729595，零成本对照为1，直接解除约27.04–28.54个百分点的表达折减。这是固定个体上的直接算术效应，不能解释为零成本群体跨代增加相同比例的后代，或成本决定了专化。
- 回归检查分开改变感知轴和处理轴，确认两条直接功能通道没有被错误混用。它不替代生态条件下的长期因果对照。

详细表：`fixed_panel_individual_hosts.csv`、`fixed_panel_individual_species.csv`、`fixed_panel_distributions.csv`、`fixed_panel_quantiles.csv`。

## 4. 双向反馈控制E：执行完成，科学判别不足

使用现有单祖先配置，8株植物、16只昆虫，同格起始；每个位点选择最小等位基因ID形成纯合单态初态。四情景分别允许双方、仅植物、仅昆虫、双方均不发生突变，种子固定为20261021–23，原定运行10代。固定方因初始单态且无新突变，重组不能产生性状差异；这不同于原多态正式批次的mutation_off。

12次运行全部在第4或第5代双方灭绝，同一种子的四情景具有相同数量轨迹；突变事件数为0–16。没有重选初态或种子保活。存续的固定方逐份等位拷贝和全部原发性状均与祖先精确相同；空群体标记 `extinct_vacuous`，不能当作通过一次遗传传递验证。

固定植物只覆盖3–4个非空后代快照，固定昆虫只覆盖1–2个。`fixed_control_validity.csv`逐情景列出有效范围。亲本贡献检查通过，但早期灭绝使这组设计缺乏检验双向适应的时间和变异积累；不能以数量轨迹相同推论双向适应不存在。`control_summary.json`中的fixed_assertions表示程序断言执行，必须结合上述非空范围解读。

**E的结论为“不具判别力”，不是“共同适应通过验收”。** 下一轮需事先设计能在有限时间内检出两方向选择响应的控制，并分别处理初态变异与人口学承载；不得将单纯延长已灭绝批次或关闭多态群体突变充当解决方案。
