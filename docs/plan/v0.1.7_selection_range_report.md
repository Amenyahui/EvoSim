## 1. 结论与证据边界

**合法植物化学域内存在处理能力影响幼虫存活的未饱和区，但现正式实验起点完全处于处理饱和区，全程也几乎没有进入未饱和区。** 这是函数与现有状态的核定，不是“已发生适应”或“共同适应不存在”的结论。

在事前固定的 `{0, 0.25, 0.5, 0.75, 1}³` 网格上，六条正式轨迹第0、200代的全部昆虫模块，对高防御寄主显示不同的利用系数和无竞争存活期望。实际全程169,241条接受后的幼虫事件中，169,237条的q达到1（99.9976365%），只有4条略低于1；86,819条存在资源竞争（51.2990%）。因此，前轮8株祖先寄主面板的饱和结论没有被当作全程事实直接外推，而是得到全量事件检查的支持，同时发现了4条例外。

三个种子在两个处理间具有相同祖先状态；每处理有3条轨迹，不能把6份状态或大量昆虫个体当作6个独立祖先重复或增加科学重复数。第200代存活成虫面板也不能代表此前所有新生幼虫；全程事件检查用于弥补这一存活者筛选。

## 2. 真实函数与饱和边界

核对 `helpers/chemistry.py`、`modules.py`、`traits.py`、`ecology.py` 和 `substeps/lifecycle.py`，与正式源码快照逐文件SHA-256一致。

植物合法化学坐标为x=(x₀,x₁,x₂)，每轴范围[0,1]。真实映射为D=(x₀,x₁)，VOC=(ηx₁,x₂)。因此x₂改变线索与植物成本，不直接改变本次强制配对后的处理负荷。

处理模块j在底物k的权重为

`a[j,k] = exp(-0.5*((t[j]-feature[k])/width)^2)`；
`I[k] = Σj expression[j] * a[j,k] / (idle + Σk a[j,k])`。

表达量与调谐中心决定两个有效处理容量I；分配包括idle通道，不是两种底物各自免费获得全部表达量。真实利用函数为

`q = min(1, min_k I[k]/D[k])`，D[k]=0时该比值按正无穷处理。

只要两个正防御分量都不超过对应容量，q=1；D=(0,0)也为1。至少一轴D[k]>I[k]时进入q<1区；进一步提高非瓶颈轴的容量不必改变q。因此“容量改变”本身不能推出“性能提高”，q<1也不保证每个模块都受正向选择。

真实资源账本为dᵢ=dmaxᵢqᵢ，Tₕ=Σdᵢ，γₕ=min(1,Rₕ/Tₕ)，gᵢ=γₕqᵢ。生命周期直接用Bernoulli(g)决定幼虫是否成为成虫。接受前的拒绝单列；events仅记录接受后幼虫，不含拒绝卵。

- 无竞争且R≥dmax时，g=q；此时容量提高能否增加存活只由q的瓶颈决定。
- 资源受限时，提高某个幼虫q可改变其相对资源份额，收益取决于同寄主其他幼虫。若同寄主所有q按同一比例提高，γ会反向变化，g可保持不变；不能把无竞争收益直接移到竞争环境。
- 只有一只幼虫但R<dmax时，g=min(q,R/dmax)，也可能出现资源上限。本轮固定R=dmax=1，排除了该混淆。

`settle_feeding`同时返回诊断量wi，但当前生命周期不以wi抽样幼虫存活；不能把wi或成年模块fi当作实际幼虫存活概率。

## 5. 母源成本与幼虫收益的权衡

真实母体倍率为 `fi=max(0,1−0.125*(processing_expression_0+processing_expression_1)−0.05*(sensory_expression_0+sensory_expression_1))`。它在成虫交配及潜在卵产生阶段作用，幼虫继承父母基因后再按自己的模块取食与存活；母亲和子代的模块不是同一个对象。

祖先群体平均fi约0.719747–0.720048，其中处理表达成本约0.199969–0.200156，感知成本约0.079975–0.080097。第200代平均fi为0.714580–0.729595。现有祖先条件下，进一步提高处理表达若仍处于q=1，不提供直接幼虫摄食收益，却可提高母源表达成本；这指出了可能存在的成本选择通道，**不证明观察到的表达变化由该通道造成**。

在未饱和区，提高瓶颈容量可能提高子代g，却付出母源卵数代价；调谐也可重新分配容量，产生底物间权衡。竞争、拒绝、遗传分离、两性配偶可达性与人口数量会改变跨代贡献。只有在明确固定配偶、接受率、子代模块对应与资源条件的简化家系比较中，才可把“潜在卵倍率×子代存活期望”当作条件性贡献指标，不能直接用同一个成年个体的fi×q断言其真实适合度或适应性。

## 6. 双向对照设计所需条件

本轮未执行新群体模拟。有效双向对照至少需要同时满足：

1. **预先声明的遗传变异。** 两方演化处理需有可遗传变异或足够突变输入；原纯合单态微群体四五代灭绝的设计不足。关闭突变并不能固定原多态群体；若用“固定方”，必须验证非空各代基因型及功能性状确实固定，或把对照明确命名为“无新突变”。
2. **覆盖双方可响应区。** 植物防御分布需与昆虫容量边界交叠，且植物防御变化能改变食害/存活/后代贡献；不能只看到q<1就称双向选择成立。网格0.75附近是合法域内的函数探针位置，不能据此事后调高正式防御来保活或宣称生态最优。
3. **足够存续和传递窗口。** 预先固定初态、规模、空间配置、种子和计划代数；使用能支持局部异交与两性繁殖的人口学设计，独立核对每代有效母株、兼容配偶、成虫雌雄与贡献家系数。所有预注册种子均保留，灭绝记为设计/人口学结果；不得筛种子、追加移民、取消异交或缩放成本以换取成功。
4. **明确资源条件。** 先在固定R=dmax、无竞争的家系/功能对照中检验方向，再在完整共享资源下检验生态响应。若全程主要γ<1，需分别报告容量收益与资源分配，不把两者混为适应。
5. **成对四情景与交叉测定。** 双方可变、仅植物可变、仅昆虫可变、双方固定使用相同预注册起点与配对种子；预定义非空传递窗口和效应阈值。以祖先与后代双方交叉组合测定真实q/g、母源成本、植物食害与后代贡献，分别识别植物响应、昆虫响应及交互项；数量存续或代数延长本身不能替代该判别。

现有证据支持先建立这些条件并核验传递窗口，再讨论共同适应。没有证据要求新增花期、定居或成种模块。
