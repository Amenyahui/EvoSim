# v0.1.7：恢复原成年空间交配的基线修订

日期：2026-10-29。按用户要求撤回错误加入的交配前寄主定居，不保留开关；植物花期也已撤回。功能模块和只读谱系观察继续保留。本文记录当前基线，旧实施记录和文献报告保留原文与原测试事实。

## 1. 当前实现合同

昆虫的顺序恢复为：

> 前轮幸存幼虫从出生寄主扩散 → 当前成年位置 → 同祖先兼容池、异性及半径约束的局部配偶池 → 母体潜在卵与逐卵择主 → 逐成功卵从既定池均匀抽父、SLiM遗传 → 子代自身处理能力与同批资源竞争 → 一次幼虫存活 → 从出生寄主扩散为下一代成虫。

母体逐卵选择不移动当前成虫或重建当前配偶池，未来产卵寄主不能决定此前交配。感觉表达/调谐可改变卵的去向，并通过下一代出生位置与扩散影响未来空间分布；它不直接制造当前寄主相关交配。

已删除交配前定居实现、`adult_settlement_enabled` 配置键、专属 `adult_settlement.csv` 和 `metadata.settlement_semantics`。带旧开关的配置必须明确拒绝，不静默忽略，也不保留关闭模式。`parents.mating_row/col`、`candidate_mate_ids/probabilities` 保留，用于昆虫和植物实际位置/配偶池的独立审计与只读观察。

植物维持三化学投入轴和原繁殖：受食后抽存活；存活母株需有局部同祖先兼容池、非自身的存活父本；按Poisson(`lambda_P F_m phi`)产生后代，逐后代均匀有放回抽父，经SLiM遗传并从母株格扩散。无花期、物候交配核或其他新增植物生殖隔离机制；防御/VOC、合成成本、受食反馈及遗传演化继续执行。

## 3. 理论及证据边界

保留两个感觉模块、两个处理模块，每个具有可遗传表达E和调谐中心mu。固定模块数、一维化学特征、高斯核、固定宽度、带惰性通道的预算式处理容量、固定感觉价性，以及只折减母源潜在卵的线性表达成本，均是项目假说。文献支持感觉、底物处理及共同演化等机制层次，不直接验证这些函数、系数或真实家族对应关系。功能公式数值没有因本次恢复成年交配而重新拟合。

植物化学性状继续参与共同演化，但当前没有额外的植物适应性成种机制。保存基因型的阈值图分群、持续窗口、split/merge/termination及网络节点只用于观察，不进入交配资格、生态计算或SLiM；候选谱系不等于新物种，群数或短程网络变化不证明物种形成、稳定共存或长期共同演化。

旧v0.1.6匹配起点核定和旧v0.1.7机制检查不能代替当前基线验证。恢复交配顺序不保证种群存续、寄主专化、隔离或谱系分裂，不以挑种子、提高lambda或改变存活下限保证预期结局。
