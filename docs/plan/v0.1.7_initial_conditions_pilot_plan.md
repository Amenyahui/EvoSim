# v0.1.7 三种初态短程人口学与选择暴露筛查计划

日期：2026-10-29。此计划在本轮任何群体更新之前写定。目标是逐项检查传递窗口与实际功能暴露，**不是验证共同进化、推断适应或寻找保活参数**。

## 1. 固定输入与全部运行

按 `v0.1.7_initial_conditions_design.md` 的原有输入运行三种背景，每种均使用20261021、20261022、20261023，合计9次，每次20个更新代（记录g0–20）。执行顺序为saturated、overlap、exceeds，每组按种子升序；无论任何指标通过与否，九次全部保留，不筛种子、不追加种子、不改变参数或运行期限。

| 背景 | `genetics.background.plant` | 既有g0容量关系 |
| --- | --- | --- |
| saturated | (0,0,0) | 全组合q=1 |
| overlap | (0.35,0.15,0) | 防御与处理能力部分交叠 |
| exceeds | (0.45,0.25,0) | 防御上界超出处理能力上界 |

各份配置相对于已保存的对应g0配置，**只有** `simulation_metadata.num_steps_per_episode` 从0改为20。包括双物种植物各200、昆虫400，植物种内/种间竞争0.02/0.005，以及双方既有突变设置在内的其他全部参数不变。两植物种是事先存在且不能互交的祖先种；本试验不从单祖先产生新种。种子之间的初始随机布局不强行相同；同一种子下三背景的遗传型、空间位置、性别及昆虫模块相同。

初步复核已逐项校验先前118个输入和24个输出文件的SHA-256，并用真实初始化重新核对九份配置与g0数组、正式同种子祖先、无裁剪及化学成本；执行前的源码快照与配置保存在 `codex/validation/v017_initial_conditions_pilot_20261029/`。x₁同时影响防御和VOC线索，且共享部分按防御成本计费；overlap/exceeds相对saturated每株防御成本分别增加0.0625/0.0875，独立VOC成本不变。这个耦合是输入的一部分，不把三组差异解释为纯防御效应。

## 2. 分别记录的门槛和分母

每个情景×种子单独报告以下指标，失败、灭绝和零分母都保留，不将不同门槛合并成通过或失败的单一科学结论：

1. **人口非空**：P1、P2、H1在g0–20各快照分别是否持续非空；给出各自首次为空代、最终数量，以及三者同时非空的连续窗口。
2. **有效交配与实际传递**：在每个更新代、每个物种，记录存活且具有至少一个同种、空间可达兼容配偶的母本数、可达父本数和母—父候选链接数，分别记录实际有出生及有招募后代的母本数、父本数与不同母父家系数。单项门槛是每个更新代各物种至少一名有效母本，及至少一名实际出生/招募的母本和父本；该正数门槛仅是最低存在性检查，不证明足够有效群体大小或遗传功效。另记三物种同时非空且均有实际招募父母贡献的连续更新窗口。
3. **处理和资源暴露**：对每个更新代、每个实际寄主种报告接受后的幼虫数、q<1的数量/比例、γ<1的数量/比例及其交集；使用1e-12容差。另报告实际被利用的寄主数、含q<1幼虫的寄主比例以及资源受限寄主比例。潜在卵与拒绝卵单列，拒绝不能当q=0；无幼虫或无寄主的比例记空值，不记0%或100%。事件和个体不是独立重复。
4. **实际资源账本下的食害响应**：对每代实际被选中的寄主，固定已发生的寄主分配、接受幼虫、各幼虫最大需求与各寄主资源；调用真实资源分配函数，先用记录的q重构实际食害，再把该寄主防御在取食函数中设为零（q=1）并重算其资源账本。分别按全部受食寄主、实际γ<1及γ≈1的寄主和寄主种，报告有食害差异的数量/分母及差值；同时保留逐代数据。该反事实只测试直接取食账本，固定真实VOC、选择、繁殖、幼虫身份及资源，零防御不宣称是可由原QTL独立实现的遗传干预，不能估计整个生态反馈，也不能称为适应。实际γ<1时资源耗尽会使直接食害改善消失，应据实报告而非以q<1替代此检查。

还将saturated三次运行的g0–20快照及前20轮出生/事件，分别与正式 `qtl_mutating` 同种子前20轮核对，差异如实列出；这种匹配检查不改变原正式数据。

## 3. 保存、核验和解释范围

每次保留完整原始数据、实际配置、源码快照和指纹；每个运行的g0逐数组核对既有g0，逐次调用现有 `audit_run`，保存成功或失败详情。对记录的卵接受数、事件数、资源账本、g=qγ、出生及招募亲本贡献做一致性检查。若个别运行失败，也记录状态并继续其他已定运行，不凭结果换种子或调整参数。

本阶段只筛查有限时间的可观察人口与功能暴露。即便各门槛均满足，也不能据此证明选择、适应、共同适应或物种形成；共享VOC变化、成本、空间、资源竞争和漂变仍未分离。此处不运行四情景冻结因果对照：站立多态下关闭新突变仍有分离、重组、选择与漂变，不能等同冻结。后续若进行因果研究，须另行预定真正的固定方验证、配对对照和祖先—后代交叉功能测定。
