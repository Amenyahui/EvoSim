# Codex 任务：落实已经完成理论审查的 evoSim v0.1.5 植物化学功能设计

**设计依据：** 请先读取我提供的 `evoSim_v0.1.5_plant_chemical_theory.md`；本文件是唯一的本次生物学修改提案，不能自行扩大研究范围。项目以当前工作区已完成的 v0.1.5 繁殖机制修订为基线；本文规定同一目标版本内尚待实施的植物化学功能修改，不表示这些新规则已经实现。

## 第一阶段：代码与理论逐条核查（必须先做）

1. 阅读 `docs/model.md`、`docs/assumptions.md`、`docs/methods.md`、`docs/architecture.md`、`docs/parameters.md`、`docs/results.md` 和相关历史计划，以及植物 QTL 初始化、phenotype、D/Z/V 映射、成本、昆虫 I/A、寄主选择、存活繁殖的源码。
2. 列出实际采用的公式、张量维度、单位、配置键、遗传协议、输出数据结构及相关测试；重点验证此前已知公式是否与当前代码一致。
3. 报告与设计文档不兼容的实现约束。特别是如果 plant allele effect vector 仍编码旧 D/Z 四轴，不能仅在 `phenotype()` 函数改几行就假装完成；需同步更新基因型效应定义、初始 founder、校验、配置及历史兼容策略。
4. 先输出审查对照清单；若发现需引入额外的未论证生物学规则，先报告，不要自行发明。

## 第二阶段：在确认相容后实施最小修改

1. 建立三维、非负标准化植物潜在化学模块 `x=(x_N,x_S,x_V)`；沿用现有加性 QTL 遗传框架，明确效应向量的顺序及截断区间。
2. 输出 `D=(x_N,x_S)`、`V=(eta*x_S,x_V)`；`eta∈[0,1]` 为固定的标准化信号映射系数。**不要将其称作实测挥发率。**
3. 植物母源成本 `Fm=max(0,1-cD*(x_N+x_S)-cV*x_V)`；共享模块只收一次基本合成成本，额外释放成本视为未建模。
4. 保留昆虫 D/I、V/A 接口、现有寄主选择、摄食/资源与存活繁殖机制；保持 SLiM 引擎和原有生命周期，不顺带升级版本、增加毒理或诱导挥发模块。
5. 配置参数更名/删除必须显式说明，不得把原 `rho`、`B` 偷换成 `eta`；检查需要迁移时是否必须版本化 `slim-qtl-1`。历史结果保持原有模型解释和指纹。

## 第三阶段：优先同步正式理论文档

同步 `docs/model.md`、`docs/assumptions.md`、`docs/methods.md`、`docs/architecture.md`、`docs/parameters.md`、`docs/results.md`，并新增 `docs/plan/v0.1.5_chemical_shared_function.md`。正式文档必须包含公式、定义、单位/标度、变量域、文献 DOI、证据与假设的区别，且与源码一一对应。旧理论不得混留在当代有效规则中。

## 第四阶段：验证，不开展演化研究

至少验证：x_N / x_S / x_V 的独立或共享影响路径、eta=0/1、x=0/1、成本只计一次、D/I 与 V/A 维度一致、SLiM 后代遗传正确、旧版结果不被静默改写、无 NaN/Inf、无父母贡献/资源账本回归。运行 `python -m tests`、`python -m ruff check evo_sim tests example.py`、`python -m ruff format --check evo_sim tests example.py`，如命令与实际项目不匹配先说明并修正调用。

**禁止**长期演化模拟、对照机制假说检验、根据结果方向调参，以及修改本次未审查的生态规则。

最终交付：变更文件、理论—数学—代码映射表、文献来源、迁移说明、测试报告、未解决的理论问题。若存在尚未审定的重大设计歧义，停在理论审核清单，不强行完成代码。
