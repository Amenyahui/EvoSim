# v0.1.7 双向对照人口学先导报告

日期：2026-10-29。对应运行前设计为 `v0.1.7_bidirectional_control_plan.md`。
**三预定种子均未满足20代双方存续门槛，停止后续双向群体对照。**
这项结果界定可用窗口，不能据此宣称共同适应不存在，也未保证通过更大规模即可长期存续。

## 1. 执行范围与实际初态

仅执行预定both_fixed×3×20代：单祖先植物400株、昆虫400只，10×10周期网格的原随机空间初始化。
使用 `v017_single_ancestor.yaml` 的生态、成本、交配及遗传参数；唯一人口学调整是初始规模。
三种子20261021–23全部保留，没有重选布局、种子或参数，没有修改lambda、资源、配偶规则、核心代码或正式数据。
全部产物在 `codex/validation/v017_feedback_pilot_20261029/`。

每个位点用最小祖先等位基因ID形成纯合单态，双方突变关闭。
三个种子的植物化学均为x=(0.3,0.5,0.4)、D=(0.3,0.5)，昆虫处理容量均为
I=(0.6825762858835892,0.6681122761397411)。原发昆虫模块为
(0.75,0.75,0.05,0.85,0.75,0.75,0.05,0.85)。祖先任意组合q=1。

正式双植物种多态起点D₀=0.3–0.4、D₁=0.5–0.6，昆虫容量下界约0.668385/0.668765。
本先导的纯合等位组合与正式抽到的多态个体不同，不能声称昆虫初态与正式个体完全相同；
它仍处于处理饱和区。P400单祖先仅匹配正式P200+200的总植物密度，
种内/种间竞争组成、化学分布和物种组成均不同，不是正式群落的严格复制或单一布局效应估计。

实际配置逐键核对还发现单祖先配置自身的竞争系数不同：本先导P1→P1为0.05，
正式P1/P2种内0.02、种间0.005。该差别随既有单祖先配置继承，未在本轮调参，
但会改变密度负担，不能声称先导与正式实验生态参数全部相同。
两者植物lambda均为每种2，昆虫lambda为4，寄主每株资源R=1、幼虫最大需求=1，
sP0=0.5、sI0=0，植物成本0.125、昆虫处理表达成本0.125、感知表达成本0.05、VOC成本0.05；
上述共同物种数值、模块宽度/idle、10×10网格、搜索半径2、竞争/植物扩散/昆虫扩散半径1、
花粉半径1、昆虫配偶半径2均已核对一致。
所以本先导昆虫灭绝与正式六条200代轨迹中昆虫存续并不矛盾：遗传组成、植物组成和竞争背景均不同。

## 3. 配偶、家系与食害证据

每种子逐代有效有配偶母本、实际母源贡献、招募母本、招募父母配对家系数以及昆虫雌雄，
保存于 `demographic_windows.csv`。植物g0–19每代均有贡献母本；
每种子最少贡献母本分别4、4、8株，最少招募家系分别6、5、12。
昆虫能产生招募的更新轮分别为g0–12、g0–7、g0–12；对应最少招募母本均为1。

昆虫灭绝前最后非空更新代分别g13、g8、g13，成虫性别为3雌0雄、0雌2雄、0雌2雄，
三次有效有配偶母本及当轮后代贡献均为0。这是末轮直接无繁殖的机制，
不能把此前整个衰退只归于性别或配偶限制。
g0昆虫招募已从400降为262、301、294，植物400降为166、148、165，
说明在最后性别耗尽之前已有明显人口下降；本先导未分解其全部原因。
