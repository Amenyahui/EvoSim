# v0.1.7 双向选择对照：先导设计与判别门槛

日期：2026-10-29。本文件在新先导运行前写入。产物统一放在
`codex/validation/v017_feedback_pilot_20261029/`；不修改正式数据、生态公式及默认参数。

## 1. 两个问题分开回答

1. 人口学资格：增大初始规模并恢复原随机空间分布，能否提供非空后代传递窗口？
2. 双向响应资格：两个方向是否有可遗传响应及可识别的贡献收益？仅存续、发生突变或性状改变均不算通过。

有效区间报告已发现正式祖先条件的处理饱和：实际169,241条幼虫事件仅4条q<1。
合法防御0.75附近存在未饱和功能区，但这是函数探针，不能直接当作可存续的遗传初态。
本人口学先导不调整植物化学值，也不把更大种群下的新突变差异称为共同适应。

## 2. 唯一预定人口学设计

复用 `v017_single_ancestor.yaml` 全部生态、空间、交配及遗传映射参数，仅将初始规模设为
单祖先植物400株、昆虫400只，与正式P200+200/H400保持总密度一致。
10×10周期网格、原初始化随机分布，初始坐标为null，由固定种子生成；不再全部放进同一格。
这保持总密度而非完整双植物种组成，不能把单祖先结果直接外推为正式双种群落结果。

每个位点固定使用现有祖先表中最小allele_id，频率1，形成纯合单态；不是根据存续结果选祖先。
三预定种子为20261021、20261022、20261023；每次最多20代，record_every=1。
不改lambda、资源、成本、配偶半径，不追加移民，不因失败更换种子、规模或布局。

本轮先且仅执行双方固定的3次人口学先导。保存全部种子，包括灭绝。
事先人口学门槛为三次均在g20双方非空，并且g0–19每方均存在有配偶、实际贡献后代的母本。
门槛失败即停止这套双向群体实验；门槛通过也仅表明20代有限资格，不保证更久存续。
处理选择饱和和缺少既定可变初态的问题尚在，因此本轮不自动执行另外9次突变处理。

## 3. 后续四情景的固定含义

在同一个预先定义并获核验的祖先状态上，按同一批种子配对：

| 情景 | 植物 | 昆虫 |
| --- | --- | --- |
| both_mutating | 单态起点、原突变率 | 单态起点、原突变率 |
| plant_only | 单态起点、原突变率 | 单态、无突变 |
| insect_only | 单态、无突变 | 单态起点、原突变率 |
| both_fixed | 单态、无突变 | 单态、无突变 |

同一初态指每种子四情景的ID、基因型、原发性状、性别及坐标逐数组一致；三种子具有独立随机布局。
四情景仅突变开关不同；改变事件数会使后续随机流不同，不能假定整个轨迹共享随机事件。
固定方因无站立变异、无新突变而真正遗传固定，但数量、空间与互作环境仍可变。
若未来使用站立变异，需另行预注册怎样在固定处理保持祖先分布；关闭突变本身不构成固定。
这四情景检验“允许新突变”的差异；即使观察到差异，也不能单凭它们识别双向选择或共同适应。

## 4. 必须保存和核验的证据

实际配置、种子、初始化规则、脚本/配置输入/模拟源码SHA-256，g0快照及每个初始化数组指纹。
逐代对固定方全部等位拷贝和全部原发性状精确比对祖先；空群体记extinct_vacuous，不能记pass。
记录每方非空后代代数、双方共存窗口、有效配偶母本数、实际贡献母本数、贡献家系数、成虫雌雄。
按真实事件记录q、g、gamma的分子分母，拒绝卵单列；核对g=q*gamma和亲本贡献链。
先导已有内置assert检查，失败保留输入与已写出的原始产物。

## 5. 双向响应实验另需预定的判别

人口学通过后，仍需在不改变核心规则下预定一个合法可遗传初态，覆盖处理瓶颈与植物防御收益区。
不能由本先导事后选存续最好或效应最大的化学参数；0.75和1仅是有效区间报告中的功能探针。
首先用祖先/后代的植物×昆虫四格交叉，在固定R=dmax、无共同消费者条件下测真实q/g与母源成本；
另外使用完整共享资源的真实食害、植物存活、兼容母本后代贡献检验植物方向。
区分昆虫端响应、植物端响应及交互；双方各自变化不是互惠适应的充分条件。
每方向效应须按独立种子报告，并报告变异输入、可响应区占比、资源限制及有效传递代数。
样本量和最小科学效应阈值需在该实验运行前确定；本3种子20代先导不给显著性或长期适应结论。
