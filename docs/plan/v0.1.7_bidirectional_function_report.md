## 1. 结论及范围

**当前规则允许植物防御、昆虫处理模块和母体感知模块改变条件性后代贡献，但方向取决于处理瓶颈、资源竞争、表达成本与候选面板。** 无竞争时存在双方可响应区；固定竞争可完全抹掉本设计植物防御的存活收益，成本也可反转昆虫处理或感知的收益。这不是共同适应已发生的证据，也不保证这些功能状态构成能长期存续的群体初态。

本轮是确定性函数干预，不进行遗传传递、群体选择或经验参数估计。沿用正式批次 `results/results_v0.1.7/200gen_H400_corrected_20261029/data/mutation_off/rep01/metadata.json` 的完整配置；该文件仅提供参数，不把该重复当作本轮科学重复。植物同种竞争系数使用正式P1→P1=0.02，未误用单祖先先导的0.05。

## 2. 事前设计与固定条件

驱动在计算响应前写 `prespecified_design.json`，保存完整网格与所有候选面板；全部结果保留，未按效果挑点。化学网格为 `{0,0.25,0.5,0.75,1}³` 共125点。基准昆虫模块为 `(0.75,0.75,0.05,0.85,0.75,0.75,0.05,0.85)`，与先导纯合祖先原发模块一致；容量约 `(0.682576286,0.668112276)`。当前正式祖先化学域与容量边界的关系见 `v0.1.7_selection_range_report.md`。

- A：125植物点×无/1固定基准幼虫竞争者，共250行。每株资源R=1，每幼虫dmax=1。三株同种兼容植物在同一格，焦点受食，另两株固定化学 `(0.3,0.5,0.4)`、不受食害、存活率1；三者互为异交候选。它们的资源各自独立，另两株作为供粉者和母株参与真实繁殖期望。局部密度相同，真实竞争函数给出三株共同phi=1/(1+3×0.02)=0.943396226。焦点防御只改变焦点资源账本，供粉伙伴条件保持不变。
- B：处理表达0/1轴和调谐2/3轴逐轴各5水平，其他模块坐标固定，共20条模块干预×125植物点×2资源竞争条件=5000行。母体数组与子代数组独立；明确条件为同型纯合双亲、无突变、同型子代，因而子代原发坐标可设为对应母体坐标。这里是合成功能干预：没有构造实际QTL等位表或运行减数分裂，不保证全部坐标都由现有祖先等位库实现。
- C：感知表达4/5轴和调谐6/7轴逐轴5水平，固定后代基准处理模块。三个预定面板各8株，共20×3×2=120行；所有候选同格可达，真实 `choose_hosts` 核对每次candidate_size=8及全部候选ID。面板为8个`{0,1}³`角点；aligned为4株`(0.5,0.5,0.25)`和4株`(0.75,0.75,0.75)`；opposed为4株`(0.5,0.5,0.75)`和4株`(0.75,0.75,0.25)`。完整D/V、重复候选身份在 `candidate_panels.csv`。选择使用真实scores及含外部拒绝项的概率，不强制接受。

B/C的家系读数额外固定：成年母亲已有兼容雄性，父本存活和配偶可达性不变；每个潜在卵独立获得一份新鲜寄主及预定竞争者。它不是把随机Poisson整窝卵挤入共享8株后得到的真实群落招募期望。C只改变母亲感知，子代利用模块固定；没有把母体和子代视为同一对象，也不把C当作感知性状遗传效应。

## 3. 复用公式与完整植物父母贡献

调用 `chemistry.outputs` 得D/V，`modules.effective` 得处理容量I，`ecology.settle_feeding` 得真实q、资源分配、食害h、幼虫g和植物成本；`modules.maternal_fecundity` 单独给母源成本。q为正防御分量I/D比值的最小值并截顶1，零防御不产生除零；`g=q×gamma`、`h=X/R`。植物实际存活为 `S=sP0+(1−sP0)(1−h)`，繁殖倍率 `fp=max(0,1−0.125×sum(D)−0.05×x2)`。

植物母源期望使用真实 `demography.maternal_moments`：`M_i=S_i×[1−prod(1−S_donor)]×mu_i`，`mu_i=lambda_P×fp_i×phi_i`。父源按 `lifecycle.sample_parents/draw_fathers` 的联合存活及均匀存活供粉者规则枚举三株全部8种存活状态；每种状态中存活且有配偶的母株产生期望mu，均分给该状态的存活供粉者。枚举母源与真实函数逐项核对，全部母源和全部父源总数相等。焦点指标为 `(母源+父源)/2`，遵循亲本核贡献记账；不是把S×fp当完整贡献。

本设计另两株S=1，焦点永远有配偶。焦点父源期望简化为 `S_focal×mu_donor`：每个另母都有另一株始终存活的供粉者；焦点也存活时均匀二选一。父源变化来自焦点能否存活并供粉，不是焦点自身fp直接作用于其他母株。

B的条件家系指标为 `lambda_H×fi_mother×g_child`。C每潜在卵的纯选择表现为 `E_selection=sum(candidate_probability×g_fixed_child)`；拒绝卵贡献0。另报 `E_selection/acceptance`，不丢弃拒绝项。加入成本后为 `lambda_H×fi_mother×E_selection`。这里lambda_H=4，fi的处理表达成本系数0.125、感知表达成本0.05；上述乘积只在已声明的独立卵条件下成立，不称为无条件真实适合度。

## 6. 感知：纯选择与表达成本分开

`sensory_response.csv` 保留每候选概率、拒绝率、接受后条件表现、每潜在卵表现与成本。三个面板、所有20条感知干预和两种竞争条件全部保存；没有优化候选或选择有利感知轴。

aligned面板无竞争时，表达轴4从0升1，每潜在卵纯选择表现从0.885144升至0.916299，拒绝率从0.068692降至0.033816；但加入感知表达成本后的条件家系从2.743946降至2.657266。不能只用接受率或选择收益宣称净适应。corners面板同轴的纯选择表现反而从0.712482降至0.695751，条件家系从2.208694降至2.017679，表明母体受线索吸引不必改善后代利用。

固定竞争者还可改变排序：corners同轴的每潜在卵表现改为0.471826→0.482492。这是各候选资源账本和拒绝共同作用，子代处理模块并未改变。感知调谐轴无表达成本变化，仍因面板关系产生正或负方向，所有端点差见 `C_endpoint_contrasts.csv`。
