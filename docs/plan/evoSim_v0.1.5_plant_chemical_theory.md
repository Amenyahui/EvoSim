# evoSim v0.1.5：植物化学性状、双重生态功能与成本——理论设计定稿（供实施核对）

日期：2026-10-27
定位：**机制设计文档**；不包含正式模拟验证，也不代表现有 v0.1.5 仓库已经采用这些规则。

> 审查限制：本次无法从环境中读取 GitHub `v0.1.5` 的完整源码，故本设计提出时，旧公式依据已知的版本说明及此前讨论：`V=clip[rho*B*D+(1-rho)*Z]`、`Fm=max(0,1-cD*sum(D)-cV*mean(V))`。进入代码阶段前，应由 Codex 对照实际仓库逐项核验变量、维度、单位、生成顺序与 QTL 配置；不一致须先报告，不得静默套用。

## 1. 科学问题与适用尺度

研究植物基因型产生的化学性状如何同时影响 **昆虫取食时面对的防御负荷** 和 **局部候选寄主识别的挥发线索**（保留原算法，尚无远距离气味搜寻）。这两条功能路径共同影响昆虫选择及利用，改变后代的遗传贡献。

不试图在 v0.1.5 中模拟单一真实代谢物的精细生化途径、扩散流场、诱导表达或具体昆虫嗅觉受体动力学。此阶段保留现有的毒素—抗性瓶颈模型和寄主选择算法，避免跨模块同时修改。

## 2. 已有文献支持的事实、与模型假设的界限

1. **化学防御与气味联系真实存在，但并非全面重叠。** 芥子油苷本身不挥发，其酶促水解可产生异硫氰酸酯等挥发性产物；部分萜类能够同时承担驱避/毒性与嗅觉线索等作用。故“共享化学模块”可以是共同代谢前体/生化途径，**不必是假定同一分子在组织和空气中保持同一浓度**。[1, 2]
2. **VOCs 不全是狭义植物次生代谢产物**：例如绿叶挥发物可来自脂肪酸相关途径；合成、储存、损伤诱导和释放是不同过程。[1]
3. **昆虫可以依据植物挥发物及其组合识别寄主**，但其响应可以依赖特定化合物、比例、剂量和背景，不必是欧氏距离或线性转化。[3]
4. **防御投入可能具有资源分配成本**，但成本系数和线性、等权表达属于明确的模型简化，并非生理定律。[4, 5]
5. **最限制性防御—抗性关系**可保留为 Speed et al. (2015) 风格的抽象生态机制；v0.1.5 不将它误称为酶动力学。[5]

## 3. 模型基本变量（无量纲，必须注明归一化窗口）

对每一株植物定义潜在的、受基因型影响的三个化学功能模块：

- `x_N ∈ [0,1]`：主要贡献非挥发性防御负荷的合成/投入能力。
- `x_S ∈ [0,1]`：在组织内提供防御，且通过共享生化途径能贡献挥发信号的能力。
- `x_V ∈ [0,1]`：主要贡献挥发信号、暂不赋予直接摄食毒性的能力。

`x` 是**标准化化学能力/投入性状**，不是测得的单一化合物浓度，也不是由昆虫感知算法计算得到的结果。真实化学种类、组织含量、释放量及昆虫受体响应分别属于不同测量层次。

记三维潜在功能向量为 `x=(x_N,x_S,x_V)`。SLiM 沿用既定的二倍体遗传、突变和重组过程；从基因型到 x 的映射暂继续采用已有加性 QTL 框架和边界裁剪，不新增特定基因/酶、显性或上位性假设。**一旦更改等位基因效应向量的长度、顺序或语义，必须检查并相应更新遗传协议、初始化表、输出元数据及跨版本兼容规则；不得默认 `slim-qtl-1` 无需调整。**

## 4. 防御与气味两条表型输出

在一个既定且可比较的组织摄食/挥发信号观察窗口内，设：

\[
D=(D_N,D_S)=(x_N,x_S).
\]

\[
V=(V_S,V_V)=(\eta x_S,x_V), \quad 0\leq \eta \leq1.
\]

这里的 `D` 是标准化**可摄入防御负荷**两维坐标，`V` 是**标准化挥发线索强度**两维坐标。`η` 是在统一标度下共享模块对气味信号的有效贡献比例，不是实测挥发速率常数；只有在固定的观察窗口和可比较的归一化尺度下，此简单映射才可使用。

该映射是**建议的最小现象学模型**，并非化学生成或释放动力学方程。`x_S` 同时进入 D 与 V 不意味着防御物质本体浓度与空气排放通量相等。

模型假设：① 短时间内化学性状相对恒定；② 在当前观察窗口内释放对组织储量的消耗可以忽略或由合成补足；③ VOC 与防御之间的关系为固定而非诱导性；④ `x_V` 不贡献直接摄食毒性（不否认真实 VOC 可能有毒）。

若上述假设不适用，不能仅靠修改 `η` 解决，需日后建立储量—生产—释放的独立模型。

### 昆虫接口约束

- 现有昆虫抗性 `I=(I_N,I_S)` 与 `D` 对应两条防御通道，保持原 `q` 算法不变，但必须审查归一化定义与 `D=0` 的边界处理。
- 现有昆虫嗅觉偏好 `A=(A_S,A_V)` 与 `V` 两条气味轴对应，暂保持算法不变；`V` 不是昆虫已感知的适合度分数。
- `V` 轴代表什么信号以及 `A` 的单位/编码必须在 `docs/model.md` 解释一致，防止把气味强度当成化合物结构坐标或单一化合物浓度。

## 5. 最小成本函数（暂定）

建议保留两个成本系数，但改为针对底层**化学投入**定义成本，而不是对输出信号 V 的坐标均值收费：

\[
C_P=c_D(x_N+x_S)+c_Vx_V; \qquad
F_m^P=\max(0,1-C_P).
\]

参数 `c_D, c_V ≥ 0`；此时共享模块 `x_S` 的基础合成成本只记一次。`c_D` 对两个防御性模块赋予相同单位权重是**简化假设**，不是必然生物化学规律；`c_V` 仅代表独立挥发模块的合成投入，**共享模块的额外释放成本目前被忽略**。如需表现该成本，必须先定义可计量的释放量及独立资源投入，不可简单把 `c_V * mean(V)` 重新加回。

`F_m^P` 仅为母源产出乘子，不等于植物全部适合度或花粉父源贡献。保持 v0.1.5 已修订的父本资格及实际贡献规则。

如 `C_P > 1`，裁剪使母源产出为零；记录该边界，且不得根据是否出现预期演化轨迹而调整成本系数。若希望避免频繁裁剪，应事先通过生物学/数学约束选择允许参数域，而不是事后调参。

**函数性质**：在 `x∈[0,1]^3`, `η∈[0,1]`, `c≥0` 下，有 `D,V∈[0,1]^2`，`F_m^P∈[0,1]`；若输出还有裁剪，应证实不是重复或掩盖映射错误。

## 6. 需要作出的设计决策（本文件预设，待仓库接口确认）

1. 以三维 `x` 代替原先独立生成的 `D/Z` 四个输出轴；保留两个防御轴、两个嗅觉轴作为生态接口。
2. 删除旧 `rho*B*D+(1-rho)*Z` 的**默认**物理解释，不将 `rho` 和 `B` 随意复用为新释放系数。若该关系已有具体实证假设，应逐条记录并解释为何弃用。
3. 将 VOC 成本从 `mean(V)` 改为 `x_V` 对应的化学投入项，明确共享模块合成费用只收一次。
4. `η` 作为固定的非演化性有效信号映射系数；其默认值必须定义为标度约定或文献支持的参数，不能根据演化结果选择。
5. QTL 映射若出现三轴结构变化，必须更新 allele effect schema、founder data、校验、文档、版本元数据；**不重写已有历史结果**。
6. 禁止在同一版本顺带改变昆虫嗅觉、解毒、种群适合度或 SLiM 版本。

## 7. 最小数学与程序一致性测试（不属于演化实验）

- x_N 单独变化：仅 D_N 变化，V 不变； x_V 单独变化：仅 V_V 变化，D 不变。
- x_S 单独变化：D_S 与 V_S 按映射变化，成本只新增 `c_D*Δx_S`。
- η=0：共享模块不产生对应的挥发信号，但仍提供防御；η=1 为同一标准化尺度的参考映射，不代表真实释放 100%。
- x 全零与全一、η 边界、成本高至产生 `F_m=0` 等边界必须通过。
- D/I 维度、V/A 维度严格一致，且不得出现 NaN/Inf；D=0 的利用极限与既有机制一致。
- SLiM 亲代—子代基因型传递正确；三模块 QTL 效应、类型与元数据无错位。
- 文档给出手算样例，与代码值完全一致；检查资源与繁殖账本，不比较模拟结果好坏。
- 相同化学性状的计算必须可追溯到同一个遗传状态，禁止随机生成额外 D/V 而不留记录。

## 9. 理论局限与后续工作

- 本版三模块分类是一种**最小建模构型**，不代表植物实际仅有三类化合物；共享比例和联系的强弱属于未来的研究维度。
- 不纳入 VOC 浓度非线性、化学比例嗅觉、诱导/受损挥发、毒性协同、植物生物合成网络、真实基因拷贝数、资源预算、多物种成种。
- 未来审查昆虫 `A/V` 嗅觉识别的浓度与混合物比例模型，但不在同一版本替换。
- 不能用这次模型修订所得模拟结果的方向为新公式背书。阶段检查只允许检验数学与代码实现。
