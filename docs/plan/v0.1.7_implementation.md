## 1. 从文献到理论修改

Sol分别核实功能机制8篇、分化/隔离8篇原始研究，记录全文、官方摘要和索引片段的实际读取深度。两份报告为 [功能证据](v0.1.7_literature_functions_sol_2026-10-28.md)、[分化证据](v0.1.7_literature_divergence_sol_2026-10-28.md)。它们支持机制类别，具体核函数、标度、价性和成本仍为项目假设。

文献和独立理论审查带来的实际修订：

- 化学类型功能特征与D/V数量分开；不把浓度差当作底物结构差。
- 处理容量增加固定惰性通道，避免行归一化掩盖全部底物失配，也不在多个底物上重复记用同一容量。
- 感觉响应先整合VOC量并饱和，再乘表达增益和固定正/负行为读出；感觉反应不直接等于吸引。
- 成年繁殖定居独立发生于交配之前，不能反向使用未来卵寄主。
- 植物新增自己的遗传花期相位和相对花粉相遇权重；不用昆虫或谱系标签过滤花粉。
- 花期用raw mod1，明确加性遗传不是圆周平均；约束kappa≤300，避免数值下溢偷偷生成绝对禁配。
- 观察分群允许单链接桥接合并，但不据此宣布真实基因库融合或自然物种形成。
