# v0.1.6：初始关联与人口学参考核定

日期：2026-10-28。承接[70次人口学对照](v0.1.6_demographic_baseline_2026-10-28.md)，完成显式初始条件、适宜寄主替代能力及50代存续检查。所有新增运行均为开发核定，保存在codex/validation/v016_reference_qualification_20261028/；此前正式200代数据及原始默认输入保持原样。

**核定结论：保留当前生命周期和lambda=4；将“已有初始功能匹配”与“识别不匹配”分成显式配置。匹配条件通过本次有限窗口的人口学可行性检查，可以作为研究已有寄主关系变化的理论起点，但不通过“长期稳定共存已验证”的认定。S=g保留为明确的理论假设，尚无实证校准；物种形成和多物种多样性机制尚未实现。**

## 1. 已落实的修订

`v016_ancestral_matched.yaml` 使用新增的ancestral_matched_alleles.csv。与原alleles.csv相比，仅昆虫A_S两个位点的四条等位（ID32–35）在effect_2各增加0.2。两位点、每位点两拷贝、effect_scale=0.5使每个创始个体A_S增加0.4；初始频率、两等位之间的效应差、I、植物及遗传背景均保持原样。期望I=(0.22,0.62)匹配P1的D，期望A=(0.62,0.62)匹配P1的V。

这将匹配放进可遗传的基因型—表型映射，而不是依靠新的强制选择或存活补偿。它是假设已有功能匹配的初始状态，不构成自然界普遍的偏好—表现关系，也不倒填创始个体的出生寄主。遗传背景仍为零。

`v016_recognition_mismatch.yaml` 显式保留原alleles.csv：期望A=(0.22,0.62)距两寄主VOC同样远，而I已经偏向P1。因此适合研究识别不匹配下的寄主建立/失败，不能称为完全未适应祖先或已建立P1关系。两种情景并列保留，不按哪种曲线存活来重命名优劣。

新增可运行断言test_reference_baseline核对精确等位差、相同创始基因型、I不变、A增加量、无新增截断及选择方向，并用原生SLiM生成子代和独立保存数据遗传审计验证该配置。

## 2. 替代能力与存活函数

先做单态平均性状、无限资源、所有雌虫有配偶、雌性比例0.5的确定性参考计算。候选数8；双寄主候选按400株中P1/P2各200株的超几何抽样积分。这是指定候选机会的参考试验，不是局部空间IBM的精确期望，也不是R0。

P1的q=1，P2的q=0.22/0.62≈0.355，母源Fm=1−0.125×0.84=0.895。将逐卵接受、寄主分配和q对应存活合并为E，参考补充/成虫=0.5×lambda×Fm×E。

| 初始识别 | 寄主 | S=g时参考补充/成虫 | 同一参考条件下lambda阈值 |
| --- | --- | ---: | ---: |
| 原始A | 仅P1 | 1.591 | 2.514 |
| 原始A | P1/P2各半 | 1.078 | 3.711 |
| 匹配A | 仅P1 | 1.711 | 2.337 |
| 匹配A | P1/P2各半 | 1.495 | 2.675 |

原始双寄主参考值略高于1仍不能保证完整模拟增长：真实模型有有限资源、有限雌性数、局部配偶、候选机会波动、性状差异、植物更新和人口随机性。不能据此把原始200代灭绝判为程序错误，也不能把这里的阈值直接当作推荐参数。

对S=g^κ、κ=0.5/1/2的参考计算，匹配双寄主补充比分别为1.551/1.495/1.442；单P1时q=1，三曲线相同。另对上一批6个种子的一代真实出生批次固定g后重评分，原始组平均条件补充比分别为1.156/0.928/0.698，匹配组为1.333/1.198/1.040。后者不是每个重复均超过1。

这些只检查理想参考和已实现出生批次对曲线的依赖；没有对替代曲线重跑多代反馈，不能宣称长期结论对S形式稳健。完整表和条件定义保存在unlimited_reference_assay.csv、reference_assay_design.json、fixed_birth_cohort_survival_sensitivity.csv及本地执行器v016_reference_assays.py。

**处理决定：现阶段保留S=g作为最简理论闭合，不为保种加入底值或提高lambda。** g=0表示无法完成发育，g=1表示该简化模型中没有额外死亡。真实物种若需要临界体重、非线性发育或额外死亡，应依据对象和证据替换，而非依据哪条曲线能活下来。lambda=4只表示理论尺度的潜在卵基准；本次替代能力检查不能把它校准成真实鳞翅目一生卵数。

8次均完成50代，保留全部结果。仅P1时4/4存续；双寄主时3/4存续，两种植物在双寄主四个重复中均存在。峰值按代初与终点成年数量取最大值。关闭新突变不等于关闭演化：站立变异仍经历选择、漂变和重组，故这些不是固定表型的生态对照。

双寄主第四重复第27代9只成虫、3只雌虫但仅1只有配偶；第29代4只、3只雌虫但仅1只有配偶，产生2只幼虫，1只成为第30代雄虫；第30代无雌虫，无法产卵，第31代为0。这解释了最后一步的消失；此前的衰退包含多个环节，不能把整条轨迹的原因归为最后一只的性别。该重复第30代没有幼虫资源窗口，不能称为“最后虫子被毒死”。

同一种子在背景加0.4与等位效应加0.2的旧/新匹配方案下，浮点运算路径和后续随机流可能分开；只保证指定初始性状匹配，不声称两种编码产生逐代相同轨迹。原有短程结果保留原身份。

## 5. 核定后的使用边界

| 项目 | 判定 |
| --- | --- |
| 母体识别→子代遗传→子代利用→资源→成年补充的阶段闭合 | 保留；有边界测试与独立账本核查 |
| 已有寄主关系的初始功能匹配 | 显式配置已实现，有限窗口人口学可行 |
| 识别不匹配的寄主建立/失败起点 | 原始输入显式保留；利用已适配P1 |
| lambda=4与S=g | 理论参数/闭合可保留；未生物学校准 |
| 稳定共存、200代普遍存续、曲线结构稳健 | 本次不予认定 |
| 双向适应与寄主专化/转换已经证实 | 不予认定；人口存续和背景流不能单独证明 |
| OR/OBP/P450等真实分子功能、成种/多样性生成 | 尚未实现，不能由当前固定物种标签和寄主背景替代 |

至此本轮“虫子为什么消失、起点是否合理、是否应调参保种”的核定结束。后续理论建设使用与问题对应的显式起点；共同演化和宏观课题推断仍须等待对应机制及对照设计完成。
