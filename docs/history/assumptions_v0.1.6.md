# v0.1.6 — 保留假设与核定内容（原§1–6）

更新：2026-10-28。当前为 shared-chemical-1 / slim-qtl-2。完整公式以 [model.md](model_v0.1.6.md) 为准；以下区分有生物背景的机制、理论简化及实现约定。文献支持机制类别，不代表本项目函数或参数经过实证校准。

## 1. 对象、生活史和遗传

- **A01–A05：个体与交配型 [背景/假设]。** 所有对象是显式个体；植物个体具母源和父源两种功能、严格异交，昆虫雌雄异体。物种标签固定，同种双亲；无成种、迁入、种子库和孤雌生殖。两性植物双功能有原始研究背景，但严格异交是所选理论型，见 [繁殖审查](../plan/v0.1.5_reproduction.md) B1。
- **A06–A12：二倍体和标记遗传 [基础/简化]。** 每个位点母父各传一份拷贝；SLiM 5.2 实际执行原生传递和重组。默认植物6位点、昆虫8位点，每轴2位点；这些数目及默认独立连锁群不是经验染色体。Haldane标记图谱假定无交换干扰；来源切换不是完整交换次数。等位ID不代表DNA序列。
- **A13–A16：QTL效应 [理论设定]。** 植物效应3维、昆虫4维；纯加性及截断区间由YAML规定。默认逐拷贝QTL突变概率0.01、目标坐标SD0.02为理论示例，不能解释为核苷酸率。关闭新突变不停止站立变异的选择/漂变/重组。来源、突变和后代表型由保存账本核对。

## 2. 三化学模块与两条功能输出

- **A17：x为原发性状 [项目假设]。** x_N主要提供非挥发防御，x_S提供共享防御/挥发功能，x_V主要提供挥发功能。三模块不是三种化合物，不能等同真实浓度、代谢基因或物质储量。
- **A18：固定共享映射 [项目假设]。** D=(x_N,x_S)、V=(eta*x_S,x_V)。eta固定且在[0,1]；默认1为归一化参考，不表示100%排放。共享前体/途径有综述背景[C1,C2]，不证明本线性映射。假定观察窗口内性状恒定，释放消耗可忽略或补足；不模拟诱导、储存和传播。旧D/Z混合式不再是当前规则。
- **A19–A21：选择 [理论简化]。** V/A为两条气味强度坐标，按既有加权平方距离和softmax选择，可拒绝全部候选。昆虫仅在局部、随机抽样的候选内决策；没有远距离气味搜寻或受体动力学。真实识别可依赖比例、剂量和背景[C3]；现有函数并未经此文验证。本过程是每枚潜在卵由母体 A 择主；拒绝不生成幼虫，不是现有成虫死亡。
- **A22–A23：利用及竞争 [理论简化]。** 最限制性I/D通道决定无竞争取食上限，零防御通道不限、全部D=0时q=1。瓶颈有理论模型先例[C5]，不是完整毒理。多个消费者同时按需求比例分享资源；不增加毒性协同、直接干扰或先到先得。

## 3. 成本、存活、空间与繁殖

- **A24：母源成本 [项目假设]。** 植物Fm=max(0,1−cD(x_N+x_S)−cV*x_V)；昆虫Fm=max(0,1−cIΣI)。共享模块基本合成成本只收一次，不对输出V收费，额外共享释放成本未建模。cD等权和线性形式为假设[C4,C5]；不是闭合碳能量预算。Fm不决定父源资格，SFm仅为代理。
- **A25：存活 [保留的假设]。** 植物S=sP0+(1−sP0)(1−h)，幼虫S=g，均只抽一次；已补充成虫不再抽存活。没有额外Fm存活惩罚。线性关系不是普适生理定律。

  本次核定保留S=g作为最简理论闭合，β=0表示没有替代食源救援。Speed的理论存活函数有参考价值，但其固定规模、无性重填不能用于保证本模型存续。幂曲线重评分未重跑多代反馈，不能称为完整结构敏感性验证。
- **A26–A27：空间/密度 [理论近似]。** 周期格允许多个体同格；竞争φ在母株邻域按代初数量计算并折减母源产量，包含自身，不是后代落点着生概率。资源和配偶共同影响昆虫密度，不另加全局承载量。
- **A28–A30：供源 [明确简化]。** 植物存活、同种、空间和非自身条件决定植物父本池；昆虫按当前成年坐标、同种、雌雄和空间决定父本池，不要求当前寄主或重新抽幼虫存活；植物排除自身，昆虫母雌父雄。池内逐后代均匀有放回抽父本，无花粉/精子容量、性选择、交配史或竞争。Fm=0仍可父源供源，不意味着现实父源成本不存在。真实资源边界见繁殖审查B5；本版未扩展。
- **A31–A34：出生/扩散 [假设与推导]。** 性比独立伯努利，不由性染色体决定。植物母本存活且有父本时按Poisson(λPFmφ)产出有效植物后代；昆虫雌成虫有父本时按Poisson(λegg Fm(I_m))抽潜在卵，每卵独立母A择主/拒绝。旧昆虫λ数值只是示例，新语义不再是有效成年后代。幸存子代从出生寄主格扩散，植物从母株格扩散，父本不决定起点。
- **A35：无救援 [实现约定]。** 不补种、不保底、不裁断出生数制造共存；亲代不跨代保留。

## 4. 统计、版本和研究纪律

- **A36–A37：复现及计算保护。** 固定参数、版本、引擎和种子可复现；安全上限停止而不截断出生，失败更新不提交遗传贡献。不能把计算停止当生态灭绝。
- **A38–A40：推断边界。** 无真实分子序列或成种。函数正确不证明共同演化、专化或稳定；本轮只检查实现、数学边界及账本，不开展演化假说检验。参数仍多为 theoretical_placeholder，不能按预期趋势调整。
- **A41–A46：观察继续分层。** 暴露、条件偏好、利用、实际资源和双亲贡献分开。固定参考面板使用三个x坐标，不生成另一套化学性状；跨时间评估同样按各自协议读取。逐个体宽度不等于群体平均反应的宽度；q全零宽度未定义。边持续窗口是操作定义，不是永久稳定性。旧Z不得重命名为x冒充新结果。

## 6. v0.1.6 阶段、寄主背景和网络假设

- **A47：阶段分离 [项目假设]。** 以有雌成虫择主、幼虫植食的鳞翅目为抽象原型；不细分卵/蛹/成年寿命，不模拟幼虫主动换寄主。这不是鳞翅目普遍通则。Adult(t) 已完成前轮幼虫存活和扩散，当前成年坐标形成交配候选；母体只用自身 A，不读取未出生子代 I。子代由 SLiM 产生，以自身 I 参与同批资源竞争并仅一次 S=g 存活。
- **A48：母源产量 [明确重定义]。** insect_offspring_lambda 为每合格雌成虫每轮潜在卵基准，Fm 读母亲 I；不再乘她上一轮摄食收益。每个成功卵逐子代均匀有放回抽父本。母源成本、每卵独立、无储精和固定候选规则属于项目假设，不是文献精确验证的公式。
- **A49：时标与创始 [实现约定]。** reproduction_round=t，adult_cohort=t+1；子代出生至成年 ID 不变，跨类群引用加 kind。创始出生寄主 unknown，不能倒填；终点只有快照/参考诊断，不伪造下一轮幼虫事件。
- **A50：阶段贡献 [账本定义]。** 出生与成功补充分别按每个子代双亲各1/2累计，分别守恒到出生数/成年数。全部死亡者仍保留出生和亲子记录。源背景→子代背景矩阵含 unknown，覆盖同背景双亲转寄主与异背景双亲到第三寄主。它不是有效基因流率、迁移率或独立遗传群证明。
- **A51：对象 [边界]。** 固定物种层、可消失/重现出生背景群、双亲 DAG 分开。背景群按每代成年个体出生寄主归类，无需遗传同质；本版不生成候选独立谱系、不含自动成种。双亲未知时跨背景配对状态是 unknown，不默认为同背景。物种首次灭绝代与背景群暂时空缺分开。
- **A52：网络 [定义]。** 真实幼虫消费、子代出生寄主的成功补充、亲本出生背景的滞后繁殖贡献各自记账。当前成虫 A/I 的联合参考反应是反事实功能诊断，不是该成虫当轮真实取食或幼虫经历。标签及观察不改变生态/交配规则。
- **A53：初始关联 [理论情景]。** `v016_ancestral_matched.yaml` 在可遗传A效应中显式匹配P1，适用于已有寄主关系的起点；不倒填创始出生寄主，不保证两物种共存。`v016_recognition_mismatch.yaml` 保留原A且I已偏向P1，用于识别不匹配情景，不代表双方完全未适应。单寄主4/4及双寄主3/4在50代存续只构成有限窗口核定，非稳定性证明，见 [核定报告](../plan/v0.1.6_reference_qualification_2026-10-28.md)。

生活史与寄主分化证据的完整支持范围见 [计划§9](../plan/v0.1.6_plan.md)。Speed 仅为比值/线性成本先例；Auer 为果蝇寻主，Gripenberg 总体正关联并有例外；Bruce/Hare 仅核实摘要。Peccoud 为群体遗传推断，Mallet 不要求绝对零基因流，Maliet 的单亲/阈值/共现定义不直接沿用。无文献可把本项目逐卵 softmax、S=g 或出生群直接确证为自然界独立谱系。
